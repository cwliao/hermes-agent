## Findings incorporated into the revision

1. CAS predicates must include `profile_name`, not only the second id column.
2. Compatibility must be checked before WAL/journal-mode mutation.
3. DDL and migration metadata must be atomic without relying on implicit
   `executescript` commits.
4. WAL failure must be explicit degraded/error state, not silent fallback.
5. Future migrations must be ordered additive functions with immutable history.
6. Definition-of-done evidence must include release metadata, CAS tests, and
   rollback on a copied database.
7. Cross-table references must validate the same profile.
8. Migration checksums, ordering, duplicate versions, and tamper detection need
   enforceable tests.
9. Non-owner CAS takeover fails closed by default.
